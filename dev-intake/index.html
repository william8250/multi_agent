05　必要依赖、skill 与权限

添加本地 skill 文件，或填写来源路径 / URL 即可。版本、工具依赖和兼容性留到启动检查时确认。

支持文本与 ZIP：文本单文件1MB，ZIP单文件10MB；依赖总计10MB。ZIP原包保存在JSON配置内，不自动解压或执行。

可直接填写本地完整路径或 URL；选目录仅登记引用，不读取文件内容。

浏览器通常不提供绝对路径；选目录后会标记目录名，完整路径可手动填写。

08　检查与生成配置

此入口生成配置草案与待办，不会自动验证订阅、读取资料库、安装 skill、运行模型或授予权限。需求与账单附件只保留信息；本地 skill 文本和 ZIP 原包随 JSON 导出。

草稿仅保存在此浏览器的 localStorage；是否可用取决于浏览器设置。填写不会自动保存，请主动保存或导出。

接下来：检查并生成 → 导出 JSON → 到协作台导入配置。已有项目无需重填；同名不同内容不会自动覆盖。8765 与 8766 的浏览器草稿不互通。

填写后点击“检查并生成”，查看分工、成本信息和启动前检查项。
